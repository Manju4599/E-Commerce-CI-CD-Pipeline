STEPS TO BE FOLLOWED WHILE IMPORTING DATA FROM THE DATA LAKE 
step1 : 
--after downloading the file check the file size and file content with the actual file
--data integrity and checking the file metadata is important 
--to check the file meta data the following command is used 
----command used when practicing with floci "aws --endpoint-url http://localhost.floci.io:4566 s3api head-object --bucket de-learning-lake --key bronze/orders/orders.csv"
----actual command with aws "aws --endpoint-url <mention_the_actual_url> s3api head-object --bucket <bucket_name> --key <acutal_key_value_for_the_file> "

step2:
--data integrity : if meta data is same as the original file doesnt mean the file content also same 
to check the file content SHA256 checksum is calculated using file size, if the matching checksum appeared means the file content is strictly same
--to get teh checksum value run this command "Get-FileHash .\<file_name> -Algorithm SHA256"
this will result a hexadecimal value, run this on both the files if the same hexadecimal valu appeared both have the same content
